Gemini prompts

The site writes the prompts for the chip you chose; copy one and paste it into Gemini. The "Gemini prompts" menu above the editor has three items:

  • Write a new program: asks Gemini for one complete main.py. After pasting, replace the wiring and the description in brackets with your own, then send it.
  • Write a phone dashboard program: like "Write a new program", but it includes how to use every widget of the Phone dashboard and its rules, so Gemini knows commands such as board.gauge(). When a program has import dash, "Explain the program" and "Copy for Gemini" add the same guide by themselves.
  • Explain the program: for an example, or a program from Gemini, that you do not understand. Gemini says in plain words what the program does, which parts it needs and what the monitor will show, then explains it section by section. Each section names its line numbers, which match the numbers down the left of the editor.

To ask about only a few lines, select them in the editor before opening the menu; the last item then reads "Explain the selection (lines 5–12)". The whole program goes too, so Gemini sees the context. With nothing selected, the whole program is explained.

Two more prompts appear when they are needed: when the program hits an error, "Copy for Gemini" on the error card sends the error message and asks for a fix; when you paste Arduino code, the button on the notice asks Gemini to rewrite it as MicroPython.

All of these prompts hide common forms of Wi-Fi passwords and tokens, but may not catch them all; see Privacy and safety.

Talking to the board with the REPL

REPL stands for Read-Eval-Print Loop: it reads a command, runs it, prints the result, and repeats. With main.py you write a whole program and then upload it. The REPL works one line at a time, which suits checking wiring, trying commands and finding mistakes.

Commands you type here run on the board straight away, but are not saved to main.py. Variables and the effects of commands are gone after a restart or an upload.

Getting started

  1. Press "Connect board". Connecting stops any running program, and the monitor shows the >>> prompt.
  2. If a program is running (for example, just after "Upload and run"), press "Stop" first.
  3. Type a command in the box below the monitor and press Enter.

Try it

Type these commands in order. The second group uses GPIO 2, the onboard LED of common ESP32 boards. For other chips or boards, use your own pin.

1 + 1

from machine import Pin
led = Pin(2, Pin.OUT)
led.value(1)
led.value(0)

import os
os.listdir()

Typing several lines

Type for i in range(3): and press Enter, and the box starts an indented new line. After the body, press Enter twice more (a blank line, then send) to run the whole block. You can also paste several lines and press "Send". The monitor shows ===, which is the board's normal prompt while it receives several lines.

for i in range(3):
    print(i)

Put longer programs in the editor on the left and use "Upload and run", so they are saved.

The REPL really controls the hardware. As in a program, wrong pin settings can still affect connected parts, so do not type file-deleting commands you do not understand. Earlier commands stay only in this tab's memory. They are cleared when you reload or change the language, and are never saved in the browser.

Watching sensor values on a chart

The top right of the monitor switches between "Text" and "Chart". On "Chart", the numbers your program prints are drawn as a line chart, which is good for watching a temperature change, a knob turn or a distance. Data keeps being recorded whichever view is shown, so nothing is missed when you switch back.

How to print values that can be charted

The program printsThe chart shows
print("temp:", t)One line called "temp"
print("Temperature:", t, "°C Humidity:", h, "%")Two lines, "Temperature" and "Humidity". Units after a number are ignored
print(t, h)When only numbers are printed, they are called "value1", "value2" in order
  • The name is the one word before the colon (or equals sign), with no spaces. For example room_temp: works, but room temp: only takes temp.
  • Lines without numbers, error messages, >>> command lines and the chip's own messages after a restart are not drawn. Up to 8 lines can be drawn.
  • Examples 4 "Potentiometer LED dimmer", 7 "Automatic night light (photoresistor)", 9 "Ultrasonic distance (HC-SR04)", 10 "DHT11 temperature and humidity (monitor)" and 11 "DS18B20 thermometer" can be charted without any changes. Their opening comments also suggest what to try, such as turning the knob, covering the photoresistor or breathing on the DHT11.

Try it

You can try this without any parts. Upload the program below and switch to "Chart" to see two waves.

import math, time

i = 0
while True:
    print("sin:", math.sin(i / 50), "cos:", math.cos(i / 50))
    i += 1
    time.sleep(0.05)

Exporting CSV

"Export CSV" downloads esp32-data-date-time.csv. The first column is the time in seconds since the first value, followed by one column per line. A value not printed on a row is left empty. Excel and Google Sheets open it with Chinese names intact, so you can make charts, take averages or write a lab report.

The site keeps up to the latest 100,000 rows. Beyond that the oldest are dropped, and a note appears above the chart. Data lives only in this tab and is cleared when the page is reloaded, so export long recordings. To keep data for longer, see Saving sensor data to Google Sheets.

Managing the files on the board

Once a board is connected, press "Board files" above the editor to see the files on the board, and to download, upload and delete them, without installing Thonny or mpremote.

Opening "Board files" stops the program running on the board. It stays stopped after you close the window; press "Restart" in the serial monitor to run main.py again.

What you can do

ActionWhat it does
Click a folder nameOpens the folder, such as lib. Click the path above the list to go back up
Open in editorPuts a text file of up to 100 KB (such as .py, .txt, .csv or .json) in the editor, after asking
DownloadSaves the file to your computer
DeleteAsks first. A folder must be empty before it can be deleted
Upload from computer…Uploads into the open folder. You can choose several files at once, or drag them into the window. It asks before replacing a file with the same name
Save editor as…Saves the code in the editor under the name you type, such as mylib.py

The top right of the window shows how much space the board has left. Uploads and downloads are checked with SHA-256, so a file that arrives damaged is caught; if an upload fails, the file already on the board is left as it was.

Writing your own library

  1. Write a function in the editor: 
    def hello(name):
    print("Hello,", name)
  2. Press "Board files", then "Save editor as…", and type mylib.py.
  3. Close the window, write the main program in the editor and press "Upload and run": 
    import mylib
mylib.hello("ESP32")

A library for a part that you find online, such as ssd1306.py for an OLED, can also go on the board with "Upload from computer…", in the top folder or in lib, and then be imported with import.

After opening a file such as lib/ssd1306.py in the editor and changing it, save it back with "Save editor as…". "Upload and run" would save it as main.py, replacing your main program.
