Gemini 提示詞

網站會依你選的晶片寫好提示詞，複製後貼到 Gemini 就好。編輯器上方的「Gemini 提示詞」選單有三項：

  • 寫新程式：請 Gemini 寫一份完整的 main.py。貼上後，把括號裡的接線和想做的功能改成你的，再送出。
  • 寫手機儀表板程式：和「寫新程式」一樣，但會附上手機儀表板全部元件的寫法和規則，Gemini 才知道 board.gauge() 這些指令怎麼用。程式裡有 import dash 時，「解說程式」和「複製給 Gemini」也會自動附上這份說明。
  • 解說程式：看不懂範例或 Gemini 給的程式時使用。Gemini 會用簡單的中文說明程式在做什麼、要接哪些零件、執行後監控窗會看到什麼，再分段解說。每段都會標出行號，可以對照編輯器左邊的數字。

只想問其中幾行，先在編輯器選取那幾行，再打開選單，最後一項會變成「解說選取的程式（第 5–12 行）」。整份程式也會一起附上，讓 Gemini 了解前後文。沒有選取時，解說整份程式。

另外兩種提示詞會在需要時出現：程式出錯時，錯誤提示卡上的「複製給 Gemini」會附上錯誤訊息請 Gemini 修正；貼上 Arduino 程式時，提示列上的按鈕會請 Gemini 改寫成 MicroPython。

這些提示詞都會自動隱藏常見的 Wi-Fi 密碼和 Token 寫法，但不保證全部偵測得到，見隱私與安全。

用 REPL 和開發板對話

REPL 是 Read-Eval-Print Loop 的縮寫，意思是讀取指令、執行、印出結果，然後重複。平常的 main.py 是寫好整份程式再上傳；REPL 則是說一句、回一句，很適合用來測接線、試指令和找錯誤。

這裡輸入的指令會直接在板子上執行，但不會存進 main.py。重新啟動或上傳程式後，變數和指令的效果都會消失。

開始使用

  1. 按「連接開發板」。連接時，板子上正在執行的程式會停止，監控窗會出現 >>> 提示符號。
  2. 如果程式正在執行（例如剛按完「上傳並執行」），先按「停止」。
  3. 在監控窗下方的輸入框打指令，按 Enter 送出。

動手試試看

照順序輸入下面的指令。第二段會用到 GPIO 2，也就是常見 ESP32 開發板的板載 LED；其他晶片或板子請改成自己的腳位。

1 + 1

from machine import Pin
led = Pin(2, Pin.OUT)
led.value(1)
led.value(0)

import os
os.listdir()

指令用途

import machine，再輸入 dir(machine)列出模組裡的功能

from machine import Pin, I2C，再輸入 I2C(0, scl=Pin(22), sda=Pin(21)).scan()掃描 I2C 裝置，確認 OLED、LCD 的接線和位址

輸入多行程式

輸入 for i in range(3): 後按 Enter，輸入框會自動換行並縮排。寫完內容後，再多按兩次 Enter（出現一個空行後送出），整段就會執行。也可以直接貼上多行程式，再按「傳送」。監控窗會顯示 ===，這是開發板接收多行程式時的提示，屬於正常現象。

for i in range(3):
    print(i)

較長的程式請放到左邊的編輯器，用「上傳並執行」，才會保存下來。

REPL 會真的控制硬體。和寫在程式裡一樣，錯誤的腳位設定仍可能影響接在上面的元件，也不要輸入不了解的刪除檔案指令。之前的指令只留在這個分頁的記憶體，重新整理或切換語言後就會清除，不會存進瀏覽器。

用圖表看感測器數值

監控窗右上角可以切換「文字」和「圖表」。切到「圖表」時，程式印出的數字會畫成折線圖，很適合觀察溫度變化、旋鈕轉動或距離遠近。不管停在哪一頁，資料都會持續記錄，切回來不會漏掉。

怎麼印才畫得出來

程式這樣印圖上出現
print("溫度:", t)一條「溫度」線
print("溫度:", t, "°C 濕度:", h, "%")「溫度」和「濕度」兩條線，數字後面的單位會略過
print(t, h)只印數字時，依順序叫做「數值1」、「數值2」
  • 名稱是冒號（或等號）前面的一個詞，中間不能有空格。例如 室內溫度: 可以；room temp: 只會取 temp。
  • 沒有數字的行、錯誤訊息、>>> 指令列，以及重新啟動時晶片印的系統訊息都不會畫。最多畫 8 條線。
  • 範例 4「可變電阻調亮度」、7「光敏電阻自動夜燈」、9「超音波測距（HC-SR04）」、10「DHT11 溫濕度（監控窗）」和 11「DS18B20 溫度計」不用修改，就能直接畫圖。這些範例開頭的註解也寫了怎麼玩，例如轉旋鈕、遮住光敏電阻或對 DHT11 哈氣。

動手試試看

不接任何元件也能試。上傳下面的程式，再切到「圖表」，會看到兩條波浪線。

import math, time

i = 0
while True:
    print("sin:", math.sin(i / 50), "cos:", math.cos(i / 50))
    i += 1
    time.sleep(0.05)

匯出 CSV

按「匯出 CSV」會下載 esp32-data-日期-時間.csv。第一欄是時間（秒，從第一筆資料開始算），後面每條線一欄；某一行沒有印到的值會留空。用 Excel 或 Google 試算表打開，中文都不會變成亂碼，可以拿來畫圖、算平均或寫實驗報告。

網站最多保留最近 10 萬筆資料，超過時會丟掉最舊的資料，圖表上方會提示。資料只存在這個分頁，重新整理網頁就會清除，長時間記錄請記得匯出。要長期保存，可以參考把感測器資料存到 Google 試算表。

管理板子上的檔案

連接開發板後，按編輯器上方的「板上檔案」，就能看到板子裡有哪些檔案，也可以下載、上傳和刪除，不用另外安裝 Thonny 或 mpremote。

打開「板上檔案」時，板子上正在執行的程式會停止。關掉視窗後程式還是停著，按監控窗的「重新啟動」就會再執行 main.py。

可以做什麼

操作功能
點資料夾名稱進入資料夾，例如 lib。上方的路徑可以點回上一層
開到編輯器把 100 KB 以內的文字檔（例如 .py、.txt、.csv、.json）放進編輯器，會先詢問
下載把檔案存到電腦
刪除刪除前會先詢問。資料夾要先清空才能刪
從電腦上傳檔案…上傳到目前所在的資料夾，可以一次選好幾個，也可以直接把檔案拖進視窗。同名檔案會先問要不要覆蓋
把編輯器內容存成…輸入檔名，把編輯器裡的程式存成那個檔案，例如 mylib.py

視窗右上角會顯示板子還剩多少空間。上傳和下載都會用 SHA-256 檢查檔案有沒有傳錯；上傳失敗時，板子上原來的檔案不會被改到。

自己寫一個函式庫

  1. 在編輯器寫好函式： 
    def hello(name):
    print("哈囉,", name)
  2. 按「板上檔案」，再按「把編輯器內容存成…」，輸入 mylib.py。
  3. 關掉視窗，在編輯器寫主程式，按「上傳並執行」： 
    import mylib
mylib.hello("ESP32")

網路上找到的元件函式庫，例如 OLED 的 ssd1306.py，也可以用「從電腦上傳檔案…」放到板子的根目錄或 lib 資料夾，再用 import 匯入。

把 lib/ssd1306.py 這類檔案開到編輯器修改後，要用「把編輯器內容存成…」存回去。直接按「上傳並執行」會把它存成 main.py，取代原本的主程式。
