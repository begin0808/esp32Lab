開始使用

這個網站不用安裝 Arduino IDE，也不需要設定開發環境。請用電腦版 Chrome 或 Edge 開啟，用能傳輸資料的 USB 線接上開發板。

  1. 安裝驅動程式：電腦找不到開發板時才需要。板子上的 USB 晶片是 CP2102 就裝 CP210x 驅動，是 CH340 就裝 CH340 驅動。
  2. 連接開發板：先關閉 Arduino IDE 這類會佔用序列埠的程式，再按「連接開發板」，選擇跳出的序列埠。
  3. 安裝韌體：第一次使用，或燒錄過 Arduino 程式時才需要。按「安裝韌體」後，板子上原有的程式和檔案都會被清除，安裝期間不要拔 USB 線。
  4. 準備程式：選內建範例，或按「複製 Gemini 提示詞」，填入接線和功能後貼給 Gemini，再把產生的 MicroPython 程式貼回編輯器。
  5. 上傳並執行：按「上傳並執行」，程式會存成板子上的 main.py，之後通電就會自動執行。輸出和錯誤訊息會顯示在序列埠監控窗。

這個網站使用 MicroPython，不能直接執行 Arduino C++ 程式。貼上 Arduino 程式時，畫面會出現提示，可以複製提示詞請 Gemini 改寫。

支援的開發板

內建韌體是 MicroPython v1.29.0 的 ESP32_GENERIC 版本，只能用在經典 ESP32 晶片，而且快閃記憶體至少 4 MB。其他晶片或容量不足時，網站會在清除資料前停止安裝。

開發板USB 晶片狀態說明
NodeMCU-32S（ESP-WROOM-32）CP2102已實測已實測安裝韌體、上傳程式、Wi-Fi 和 MQTT。可參考腳位圖。
ESP32-S 開發板CH340C應可使用同為經典 ESP32，但尚未實測。腳位排列可能和上面的腳位圖不同，請對照板子上的標示。
其他 ESP32-WROOM-32 開發板依板子而定應可使用快閃記憶體要有 4 MB 以上。尚未逐款實測。
ESP32-S2、S3、C3、C6、H2 等依板子而定不支援晶片不同，內建韌體無法執行。
ESP8266、Arduino UNO 等依板子而定不支援不是 ESP32，網站無法安裝韌體。

電子元件與感測器

下表不是限制清單。只要能用 MicroPython 控制，表上沒有的元件也可以使用。請把完整型號和接線腳位告訴 Gemini，再依下面的注意事項接線。

  • 已實測已接上實體開發板測試成功。
  • 有範例網站有內建範例，但還沒接實體元件測試。
  • 韌體支援韌體有所需功能，可以直接寫程式，但沒有範例，也還沒實測。
  • 需加驅動韌體沒有這個元件的驅動，要把驅動程式碼一起寫進 main.py，也還沒實測。

輸出元件

元件狀態控制方式注意事項
LED已實測Pin要串聯限流電阻（例如 220Ω），長腳接 GPIO，短腳接 GND。
有源蜂鳴器韌體支援Pin通電就響，只能開關。電流較大的元件要用模組或電晶體驅動。
無源蜂鳴器韌體支援PWM要送頻率才會響，可以發出不同音高。買之前先確認是有源還是無源。
SG90 伺服馬達韌體支援PWM（50 Hz）請用外部 5V 供電，並和 ESP32 共地，不要從開發板 3V3 取電。
繼電器模組韌體支援Pin先確認模組能接受 3.3V 訊號。課堂實驗不要接市電。
WS2812 全彩 LED、燈條、點矩陣韌體支援neopixel燈數多時電流很大，要用外部電源並共地。
MAX7219 LED 點矩陣需加驅動SPI通常用 5V 供電，ESP32 的 3.3V 訊號可能不穩定，要實測。
裸 8×8 LED 點矩陣韌體支援Pin需要很多腳位和掃描程式，不建議初學者使用，改用有驅動晶片的模組。
SSD1306 OLED需加驅動I2C常見接法是 SDA 接 GPIO 21、SCL 接 GPIO 22。
I2C LCD 1602需加驅動I2C許多模組用 5V 供電，I2C 訊號可能被上拉到 5V，接線前要先確認電壓。

感測器與輸入元件

元件狀態控制方式注意事項
DHT11 溫濕度有範例dhtVCC 接 3V3，讀取間隔至少 1 秒。
DHT22 溫濕度韌體支援dht程式改用 dht.DHT22，讀取間隔至少 2 秒。
光敏電阻韌體支援ADC請接 GPIO 32–39。裸元件要搭配電阻分壓（例如 10kΩ），模組請用 3V3 供電。
可變電阻韌體支援ADC同樣接 GPIO 32–39，兩端接 3V3 和 GND。
HC-SR501 人體紅外線韌體支援Pin通常用 5V 供電，訊號輸出約 3.3V。通電後約 1 分鐘內可能誤判。

DS18B20 溫度韌體支援onewire、ds18x20DATA 和 3V3 之間要接 4.7kΩ 上拉電阻，模組通常已內建。
HC-SR04 超音波韌體支援Pin、time_pulse_usEcho 輸出常是 5V，要先分壓成 3.3V 才能接 GPIO。

請 Gemini 寫程式的訣竅

  • 寫清楚型號和腳位：例如「MAX7219 8×8 點矩陣，DIN 接 GPIO 23，CLK 接 GPIO 18，CS 接 GPIO 5」。
  • 只用一個檔案：這個網站只上傳 main.py。需要驅動時，請 Gemini「把驅動程式碼和主程式寫在同一份 main.py」。
  • 指定語言：說明要 MicroPython v1.29.0，不要 Arduino C++。網站的「複製 Gemini 提示詞」已經包含這些要求。

接線注意事項

接線或改線前，請先拔掉 USB 線。接錯電壓或短路可能會燒毀開發板。

  • GPIO 只能接受 3.3V：不要把 5V 訊號直接接到 GPIO。
  • 不要直接驅動大電流元件：馬達、長燈條等要用外部電源或驅動模組。使用外部電源時，GND 要和 ESP32 接在一起。
  • 確認腳位編號：程式裡的編號是 GPIO 編號，請對照板子標示或腳位圖。
腳位建議原因
GPIO 6–11不要使用連接內部快閃記憶體，接線可能讓板子無法運作。腳位圖上的 GPIO 9、10 標示 RX1、TX1，也不要使用。
GPIO 34、35、36、39只能輸入不能輸出，也沒有內部上拉或下拉電阻。
GPIO 25–27、GPIO 0、2、4、12–15類比輸入避開這些是 ADC2 腳位，Wi-Fi 開啟時不能讀類比值。需要類比輸入請改用 GPIO 32–39。
GPIO 0、2、5、12、15小心使用開機時的電位會影響啟動。尤其 GPIO 12 開機時若被拉高，板子可能無法啟動。
GPIO 1、3避開USB 序列埠使用，接其他元件會影響上傳和監控窗。
GPIO 4、13、16–19、21–23、25–27、32、33一般優先選用用於一般數位輸入和輸出比較不會衝突（GPIO 21、22 常用於 I2C）。

手機與語音控制

網站有兩種手機控制方式：

開發板上的網頁語音控制頁（MQTT）
範例手機控制 LED、DHT11 溫濕度警報語音控制 LED（MQTT）
網址http://192.168.x.x（監控窗會顯示）語音控制頁
麥克風語音不能用，瀏覽器不允許 http:// 網址使用麥克風可以用（HTTPS）
網路需求手機和板子連同一個 Wi-Fi，不一定要能上網板子和手機都要能上網，不必同一個 Wi-Fi
校園網路影響禁止裝置互連時會打不開防火牆擋 1883 連接埠時，板子會連不上

語音控制步驟

  1. 範例選「語音控制 LED（MQTT）」，填入 Wi-Fi 名稱和密碼，按「上傳並執行」。
  2. 監控窗顯示「已連上 MQTT 伺服器」後，記下通道名稱。
  3. 開啟語音控制頁，輸入通道名稱後按「連線」。
  4. 按語音按鈕，允許使用麥克風，然後說「開燈」、「關燈」或「閃爍」。

語音不能用時，可以按開燈、關燈按鈕，或在文字指令欄用手機鍵盤的麥克風輸入。Windows 電腦也可以按 Win + H 語音輸入。

Wi-Fi 只支援 2.4GHz。ESP32 連不上 5GHz 網路。

隱私與安全

  • 程式碼：網站不會把程式碼上傳到伺服器。程式碼只存在這個瀏覽器和你的開發板上。
  • Wi-Fi 密碼：密碼寫在程式裡，所以會以明文存在瀏覽器和開發板的 main.py。使用共用電腦或借出開發板前，請先刪除密碼；上傳不含密碼的程式可以覆蓋板子上的 main.py。
  • 貼給 Gemini 前：「複製給 Gemini」和「改寫成 MicroPython」會自動隱藏常見的 Wi-Fi 寫法，但不保證全部偵測得到。自己全選複製程式時不會隱藏，請先刪除密碼。
  • 截圖和投影：編輯器會顯示密碼，投影或分享畫面前請先遮住。上課建議使用專用 Wi-Fi 或手機熱點。
  • 語音控制：指令會經過公用 MQTT 伺服器，沒有加密保護和權限控管，知道通道名稱的人都能控制。只適合 LED 這類低風險實驗，不要控制插座或門鎖，也不要在通道名稱填入個人資料。
  • 語音辨識：語音由瀏覽器和其語音服務辨識，通常需要連網。

常見問題

按「連接開發板」後，清單裡沒有序列埠

先換一條確定能傳輸資料的 USB 線，有些線只能充電。接著確認已安裝對應的驅動程式，並重新插拔開發板。

連接失敗，或顯示序列埠被佔用

關閉 Arduino IDE 和其他分頁裡的本網站，一次只能有一個程式使用序列埠。

顯示「沒有偵測到 MicroPython」

第一次使用，或燒錄過 Arduino 程式時都會這樣。按「安裝韌體」即可，不用另外下載韌體。

安裝韌體時一直連不上

按住板子上的 IO0（BOOT）鍵再重試，開始寫入後就可以放開。

顯示「這塊板子是 ESP32-xx，目前只支援經典 ESP32」

這塊板子的晶片不在支援範圍內，內建韌體不能用。請改用經典 ESP32 開發板。

監控窗出現紅色的「程式發生錯誤」

按「複製給 Gemini」，把錯誤訊息和程式碼一起貼給 Gemini 修正，再把新程式貼回來上傳。

顯示 Wi-Fi 連線失敗

確認名稱和密碼完全正確（包含大小寫），並確認是 2.4GHz 網路。

手機打不開 192.168.x.x 的網頁

確認手機和開發板連同一個 Wi-Fi，也關閉手機的行動數據試試。校園網路可能禁止裝置互連，可以改用手機熱點，或語音控制頁（MQTT）。

沒有跳出麥克風權限，語音不能用

確認開啟的是 HTTPS 的語音控制頁，不是 http://192.168.x.x。如果之前拒絕過，請到瀏覽器的網站設定改成允許。

語音控制頁顯示「開發板沒有回應」或「離線」

確認開發板程式正在執行、監控窗顯示已連上 MQTT 伺服器，以及頁面和程式裡的通道名稱完全相同。校園網路可能會擋 1883 連接埠，可以改用手機熱點測試。

按下「停止」後，程式之後還會自動執行嗎？

會。「停止」只中斷目前的執行，main.py 還在板子上，下次通電或重新啟動時會再次執行。
