開始使用

這個網站不用安裝 Arduino IDE，也不需要設定開發環境。請用電腦版 Chrome 或 Edge 開啟，用能傳輸資料的 USB 線接上開發板。

  1. 安裝驅動程式：電腦找不到開發板時才需要；USB 直接接 S2、S3、C3 晶片的板子通常不用裝。板子上的 USB 晶片是 CP2102 就裝 CP210x 驅動，是 CH340 就裝 CH340 驅動。編輯器右上角的「設定與說明」也有這些連結，以及腳位圖、語音控制頁、手機儀表板頁、語言、風格和字體設定。
  2. 連接開發板：先關閉 Arduino IDE 這類會佔用序列埠的程式，再按「連接開發板」，選擇跳出的序列埠。
  3. 安裝韌體：第一次使用，或燒錄過 Arduino 程式時才需要。按「安裝韌體」後，板子上原有的程式和檔案都會被清除，安裝期間不要拔 USB 線。USB 直接接晶片的板子，裝完要按一下 RST 鍵並重新連接。
  4. 準備程式：選內建範例，或按「Gemini 提示詞」→「寫新程式」，填入接線和功能後貼給 Gemini，再把產生的 MicroPython 程式貼回編輯器。
  5. 上傳並執行：按「上傳並執行」，程式會存成板子上的 main.py，之後通電就會自動執行。監控窗第一行會顯示程式大小和上傳花了幾秒，接著是程式的輸出和錯誤訊息。
  6. 只是試試看：按「執行（不存檔）」或 F5，程式會直接在板子的記憶體裡執行，不會存成 main.py，見執行（不存檔）。

執行（不存檔）和上傳並執行

「執行（不存檔）」會先停止目前的程式、清空上一次留下的變數，再把編輯器裡的程式送到板子的記憶體直接執行，不會存成 main.py。連接開發板時，也可以按 F5；沒有連接時，F5 照樣是重新整理網頁。

執行（不存檔）上傳並執行
速度比較快，不用寫檔也不用重新開機稍慢
重新啟動或拔掉電源後程式消失，板子回到原本的 main.py程式留在板子上，通電就自動執行
適合試東西、改參數、找錯誤完成的作品，或要離開電腦執行

程式寫壞了也不用擔心：按「重新啟動」或拔掉電源，板子就會執行原本的 main.py。試好之後，再按「上傳並執行」存到板子上。程式讓板子重新開機時（例如深度睡眠或 machine.reset()）也一樣，醒來後執行的是板子上的 main.py，監控窗會提示。

程式結束後查看變數

程式結束或按「停止」之後，變數還留在板子上，可以在監控窗下方的 REPL 輸入變數名稱，看最後的值。例如：

total = 0
for i in range(1, 11):
    total = total + i

執行完在 REPL 輸入 total，會看到 55；輸入 i 會看到 10。找錯誤時，這比到處加 print 方便。用「上傳並執行」時板子會重新開機，所以要用「執行（不存檔）」才能這樣看。

錯誤訊息裡的 File "<stdin>", line 3 指的是編輯器第 3 行，和 main.py 的行號一樣。「複製給 Gemini」照樣可以用。

支援的瀏覽器

裝置與瀏覽器編輯器（USB 上傳）語音控制頁
電腦版 Chrome、Edge可以使用Chrome 已實測，Edge 的語音尚未實測
Chromebook 的 Chrome已實測 學校的 Chromebook 接 ESP32-S 開發板，連接、安裝韌體、上傳程式都正常尚未實測
Android 手機 Chrome請改用電腦頁面可開啟，語音辨識尚未實測
iPhone Safari不能使用尚未實測，語音不能用時請改用文字指令
電腦版 Firefox、Safari不能使用（沒有 Web Serial）尚未實測

Chromebook 只有 Type-C 孔時，用 Type-C 轉 USB-A 轉接頭接原本的 USB 線就可以，也可以改用 USB-C 轉 Micro USB 傳輸線。學校統一管理的 Chromebook 如果按「連接開發板」後沒有出現序列埠，可能是管理政策關閉了這個功能，請資訊組在 Google 管理控制台開放。

MicroPython 與 Arduino 的差異

兩者都能控制 ESP32，沒有哪一個絕對比較好。本網站選擇 MicroPython，是因為不用安裝軟體，改完程式幾秒就能看到結果，錯誤訊息也容易看懂，適合課堂和快速實驗。

MicroPython（本網站）Arduino C++
語言Python，語法簡短，容易入門C++，要宣告型別，語法較嚴格
開發環境開啟瀏覽器就能使用，要先安裝一次韌體要安裝 Arduino IDE 和開發板套件，電腦還原後要重裝
修改後上傳不用編譯，通常幾秒完成每次都要編譯再燒錄，等待時間較長
找錯誤錯誤訊息會指出行號，也可以在監控窗直接輸入指令測試編譯時能先抓到語法錯誤，執行時的問題多半靠序列埠輸出追查
執行速度較慢，一般感測和控制通常夠用快很多，適合大量運算和高速處理
記憶體直譯器本身會佔用空間，可用的較少可用的較多，比較適合大型程式
時間精準度記憶體回收可能造成短暫停頓，不適合要求精準時序的工作時間控制較精準
函式庫常用功能已內建，其他模組可能要自己找程式碼數量很多，大部分模組都找得到
適合用途入門教學、搭配 AI 寫程式、感測器和物聯網實驗相機影像、高速訊號處理、大型或要長期穩定運作的專案

同一塊板子可以換來換去，只是一次只能用一種：用 Arduino IDE 燒錄後，MicroPython 和板子上的檔案會被覆蓋；想換回來，再到本網站按「安裝韌體」即可。
